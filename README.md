# AppImage Update

You can update your AppImages, all your programs at onces automatically with this Bash Script. 

If there are AppImages you want to add in this script, please warn me. 

Support me by contributing positively, give me ideas to improve my codes. 

I will be happy about it.

## Usage

1. Download or Clone Repo
   
   ```bash
   git clone https://github.com/yburakg/appimage-update.git
   ```

2. Change directory to appimage-update
   
   ```bash
   cd appimage-update/
   ```

3. Set Permissions

   ```bash
   chmod +x appimage-update-script.sh
   ```

4. Run Script
   
   ```bash
   ./appimage-update-script.sh
   ```
